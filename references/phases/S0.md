# S0 选刊与范围 — 细则

> SKILL.md 索引表的全文版，从 v2.5 的 SKILL.md 原文逐字下沉；进入 S0 前读完本文件再动手。综述关口的判据见 [../gates.md](../gates.md)（综述分支关口一节）。

同 P0，外加三个综述专属判定写进 state.survey：**范围边界**（哪些算进、哪些明确排除，各给一条判据）、**组织轴**（按方法层级 / 按任务 / 按数据 / 按时间，只选一个主轴）、**综述的主张**（一篇好综述有一个可证伪的论点，如"报告的融合增益随基线匹配严格度缩小"，不是目录）。编辑退稿最常见的理由是"这是目录不是综述"，S0 就要把论点写出来。
G-S0 = guide.txt 在；state.survey 的 scope_in / scope_out / axis / thesis 四项非空。

**综述形态（2.11 新增）**：`state.survey.review_type` ∈ narrative | scoping | systematic。只有锁定协议、可复现检索、排除复核与 PRISMA 清单都做的才写 systematic；标题或论点自称 systematic 而 review_type 不是，G-S0 FAIL。scoping / systematic 会让 G-S3 的排除复核与 G-S5 的报告清单从 WARN 升为 FAIL。
