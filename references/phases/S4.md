# S4 汇总表与图 — 细则

> SKILL.md 索引表的全文版；进入 S4 前读完本文件再动手。综述关口的判据见 [../gates.md](../gates.md)（综述分支关口一节）。

**表全部由脚本从 coded.csv 算，图全部由脚本从项目文件画，正文与图里的每个数都能回到一行数据。**

## 表（`scripts/survey_tables.py`）
| 表 | 命令 | 用途 |
|---|---|---|
| 汇总表 tables/<name>.csv | `summary`（定义写 `coding/tables.yaml`，模板 templates/tables.yaml）；G-S4 跑 `summary --verify` 逐格重算 | 按组的 n、中位数、IQR、占比；claims.csv 的 evidence_key 指向它的行 |
| 覆盖矩阵 coding/coverage.csv | `crosstab --rows <主轴列> --cols <任务/数据列>` | 只接受单值列，保证每篇恰好计一次；空白格进路线图节 |
| 纳入研究特征表 | `characteristics --cols year,task,metric,n_test [--cite-col bibkey]` → tables/characteristics.tex + .md | PRISMA 第 17 项；coded.csv 有 bibkey 列时 Study 列写 \cite |
| 已有综述对比表 | `prior [--cols year,venue] [--covers-prefix covers_]` → tables/prior_surveys.tex + .md | prior_surveys.csv 加 covers_<维度> 列（yes/no）则出 ✓/– 矩阵，末行是本文（state.survey.this_survey）；没有 covers_ 列则出 how_this_differs 文字列 |

项目内仍可以手写 `coding/*summary*.py`（带 --verify），G-S4 两种都认。

## 图（`scripts/survey_figure.py`，风格与 make_figure 同：7.5 pt serif、PDF 矢量、source.csv、灰度预览、版面审计、figures.csv 登记）
| 图 | 命令 | 什么时候画 |
|---|---|---|
| PRISMA 2020 流程图 | `prisma --out figures/fig_prisma.png` | 系统/范围综述必画；排除理由取 screening_sheet 里摘要/全文级排除行的 reason_code 或 reason，合计 ≠ screened_abstract − included 则 FAIL |
| 年度时间线 | `timeline --by <单值列> [--cumulative]` | 论点涉及"领域在增长 / 方法在转向" |
| 覆盖热图 | `coverage`（读 coverage.csv）或 `--rows/--cols` | 零格红框 = 空白，路线图节逐格回应 |
| 证据气泡图 | `bubble --x <列> --y <列> --colour ext_val=yes` | 气泡大小 = 篇数，颜色 = 某质量指标的占比；"做得多但验证弱"的格子一眼可见 |
| 偏倚风险汇总 | `rob --domains <域列,…> --levels low,some,high,unclear --labels "列=域名,…"` | 有 QUADAS-2 / PROBAST / RoB 2 等逐域评级时；codebook 给每个域列取值集合 |

每张图跑完打印 `caption numbers:`，题注只用这一行里的数。图出来后裁图目测，figures.csv 的 inspected 改 yes。分类树、概念示意图仍走 `nature-figure`。

## 关口
G-S4 = 每张 tables/*.csv 能从 coded.csv 逐格重算（tables.yaml 或 *summary*.py 的 --verify）；coverage.csv 的格子合计 = 纳入篇数；figures.csv 至少一张图；`skew_dims` 列出的列里某值占已知值 ≥70% 时 WARN（讨论节说明是领域本身还是检索造成的偏斜）。
