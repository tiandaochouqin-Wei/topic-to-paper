# P3 搭建 — 细则

> SKILL.md 四行表的全文版，从 v2.5 的 SKILL.md 原文逐字下沉；进入 P3 前读完本文件再动手。关口判据与历史漏法见 [../gates.md](../gates.md)，失败模式总表见 [../lessons.md](../lessons.md)。

**P3 搭建**：填 state.audits（划分键、泄漏开关、关键超参与日志证据列、必需输入、烟测命令），G3 = `audit_check.py --smoke` 全绿。**实验在服务器上跑时**（用户上传、跑完传回的工作流）：填 state.bundle（入口命令、eval 命令、数据远程路径与 inputs、调度器 bash|slurm、matrix = ref/baselines/ablations 各自的参数串与 seeds），`bundle.py check` 核对矩阵覆盖 prereg §5/§6、seeds ≥ min_seeds、无 run 打开泄漏开关；`bundle.py make` 生成自包含实验包（README、check_env.py 逐项核对 CUDA/显存/磁盘/每个 clip 的输入、smoke.sh 一 epoch 烟测、run_all.sh 整矩阵可中断重跑、collect.sh 只打包关口要的文件、manifest.json 记代码 sha256）。来回三次：烟测报告 → 全量结果包 → 反常补跑。结果回来后 `bundle.py tables` 按 metric_map 从 eval.json 生成 main.csv/ablation.csv（硬件取自 hardware.json，manifest 不一致的 run 不进表），再走 G4。

**仪器校准（G3b）**：任何实验用到预训练模型、外部框架（官方 trainer/评测 harness）或自写训练循环之前，先把它当仪器校准——在 state.instruments 登记一条（模板在 templates/research-state.yaml）：① `contract` 写官方代码的输入约定（轴向 axcodes、spacing、强度窗、通道数），`source` 是官方仓库的那一行，不是记忆；② `check`：经过与实验**完全相同**的输入路径，复现官方/论文的一个数（Dice、AP、top-1 都行），脚本把实际喂给模型的约定写进输出 json 的 `applied_contract`；③ `broken`：同一校验、故意破坏输入（轴反向、不做强度归一化），读数必须落到容许带外——一个不会失败的校验等于没校验；④ `dump`：把模型看到的第一个张量画出来、标上轴向，**自己看一眼**再写 `inspected: yes`。自写训练循环没有已知数字：`kind: train_loop`，用参考实现（官方 trainer）在同一划分上的结果对账。代码里的每个加载点（from_pretrained / load_state_dict / torch.hub / timm / YOLO(...)）都要被某条 instrument 的 `match` 覆盖，自己的 checkpoint 用 `instruments_waiver`（如 `{match: "resume|runs/", reason: "own checkpoint"}`）显式豁免。代码改过而校准没重跑 = FAIL。P3 在 `instrument_check.py`（G3b）全绿之前不算完。另：有多进程数据增强时在 `audits.stochastic_keys` 登记每 epoch 写进日志的增强种子/哈希（全程同一值 = FAIL）；缩小 `main_table_runs` 会触发 WARN，要在 convention_changes 登记。
