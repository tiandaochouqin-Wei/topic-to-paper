# S5 写作 — 细则

> SKILL.md 索引表的全文版，从 v2.5 的 SKILL.md 原文逐字下沉；进入 S5 前读完本文件再动手。综述关口的判据见 [../gates.md](../gates.md)（综述分支关口一节）。

顺序：论点段 → 已有综述对比表 → 分类法节 → 审计/汇总节 → 空白与路线图 → **综述自身的局限节**（单人筛选、检索源、编码员、时间截止）。每个数字登记 numbers.csv 指向 tables/*.csv 或 coded.csv 的行。参考文献上限按刊（Information Fusion 综述 ≤300，加一删一）。
G-S5 = `gate_check.py all` + `survey_check.py claims`：claims.csv 每条主张的 evidence 指向 tables/ 或 coded.csv 的具体行并能重算；"first/only survey" 类主张必须对已有综述表逐行说明。

**综合而非罗列（2.11 新增，借自 Imbad0202 synthesis_agent 的张力清单、xingtaxueshu 的矛盾矩阵、YANZHANLIN 的段落公式）**：
- **段落公式**：主题句 → 3–5 篇证据 → 对比/冲突 → 判断 → 过渡。按概念组织，不按作者组织。G-S5 的 `writing` 部分逐段查：≥3 句、多数句以单篇引用开头、全段没有比较/归纳词（however / whereas / in contrast / most / across / consistent / 相比 / 一致 / 多数 …）的段落记为"逐篇罗列"，有则 WARN 并给行号，占带引用段落 > 30% FAIL。
- **跨研究张力清单 `coding/tensions.csv`**（模板 templates/tensions.csv）：每对研究一行，两个正交轴。pair_assessment ∈ contradiction | conditional_difference | no_material_conflict | insufficient_overlap；resolution_status ∈ resolved_in_synthesis | flagged_unresolved | not_applicable。真冲突（前两类）不能标 not_applicable，后两类只能配 not_applicable；resolved_in_synthesis 的 resolution_pointer 必须是正文里能找到的原文片段；有 flagged_unresolved 时正文必须有"未解决 / 结论不一"的表述。候选对从共享子主题、结果方向相反、同一数据集结论不同里找；一对都没有记录 → WARN（没找到分歧通常是没去找）。清单是启发式的，正文不写"所有矛盾均已处理"。
- **有界措辞**："首个综述 / 无人研究过"一律写成"在检索的数据库与日期范围内"，否则 WARN。
- **引用覆盖**：coded.csv 有 bibkey 列时，每篇纳入研究要在正文或特征表里被引，漏引 WARN。
- **报告清单**（systematic / scoping）：`templates/prisma2020_checklist.csv` 拷到 `paper/prisma_checklist.csv`，逐项填 location（§ / Table / Fig / Supplementary / N/A + 理由）。where_this_skill_produces_it 列写了每项由哪个产物支撑。未定位项 FAIL（narrative 为 WARN）。范围综述用 PRISMA-ScR、诊断准确性用 PRISMA-DTA 时换清单内容，列名不变。
