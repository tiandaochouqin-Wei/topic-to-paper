# P0 选刊 — 细则

> SKILL.md 四行表的全文版，从 v2.5 的 SKILL.md 原文逐字下沉；进入 P0 前读完本文件再动手。关口判据与历史漏法见 [../gates.md](../gates.md)，失败模式总表见 [../lessons.md](../lessons.md)。

**P0 选刊**：下载 Guide for Authors 到 `submission/guide.txt`（nature.com 用 curl 带浏览器 UA，官方 PDF 比网页可靠），硬规则抄进 state.target。**同时定 `target.family`**：cs_conf（CVPR/NeurIPS/ICML/ICLR/MICCAI…）| cs_journal（TPAMI/TIP/IJCV/EAAI/TGRS/Information Fusion…）| nature（Nature/Science 及子刊、npj、Sci Adv）；三类的章节顺序、篇幅、禁用词、统计写法在 [references/venue-profiles.md](references/venue-profiles.md)（275 篇实测），写作骨架 `templates/skeleton-<family>.md` 在 P6 复制为 manuscript.md 起点。G0 = 文件在、venue 填了。

**LaTeX 模板（2.7 新增）**：目标刊在 [../latex-templates.csv](../latex-templates.csv) 里有行时，按该行 `sty_source` 把模板的 .cls / .sty / .bst 下载到 `paper/latex/`（不随 skill 分发），然后 `latex_check.py skeleton --venue "<刊>" --title "<题>"` 生成 `paper/latex/main.tex` 骨架：documentclass 与选项、subcaption（IEEEtran 用 subfig）、`\graphicspath` 指向 figures/、按 family 的章节、一张单图与一张组合图的示例、bib 指向 paper/refs.bib。再 `latex_check.py widths --tex paper/latex/main.tex` 用 pdflatex 实测 \textwidth / \columnwidth（无 pdflatex 则用表值），把 mm 记进 state.target 备注，P5 定图宽用它。state.target 填 `latex_class`（G6d 对不上就 FAIL）与 `figure_ext: pdf`。
