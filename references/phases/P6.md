# P6 写作 — 细则

> SKILL.md 四行表的全文版，从 v2.5 的 SKILL.md 原文逐字下沉；进入 P6 前读完本文件再动手。关口判据与历史漏法见 [../gates.md](../gates.md)，失败模式总表见 [../lessons.md](../lessons.md)。

**P6 写作**：**先按 family 取骨架** `templates/skeleton-{cs_conf|cs_journal|nature}.md` 作 manuscript.md 起点（nature：Abstract ≤150 词一段 → 无标题引言 ≤600 词末句 "Here we show" → Results 小标题是主张句 → Discussion ≥12% → Methods 在最后；不写 Related Work / Conclusion / 贡献列表 / 正文公式 / "state-of-the-art"，消融写 control experiments，每个比较给 n、检验、p 或 CI。cs_conf：Intro 末尾贡献 3–5 条 → Related → Method 带公式 → Experiments 含 Ablation 小节 → Conclusion，主文 8–10 页附录放全表。cs_journal：同 cs_conf 但 Related 展开 2.1–2.3、Problem Formulation、实验 8–11 小节、Discussion/Limitations 子节、摘要 ≤250、Highlights 另文件）。顺序固定：① 填 claims.csv（每条主张：陈述、数据集、口径、证据文件、表/图、作用域词）；② `draft_plan.py plan` 从 gap_map / prereg / claims / results 自动生成**各节必写清单** paper/draft_plan.md（引言：重要性行、每篇关键论文的失效点、§0 现象、§1 主张一句话、贡献条目含数字；方法：§0 原因假设作动机段、每个有消融的组件、借来方法的失效点与修法；结果：每个预注册基线与消融的名字、ours 相对最强基线的相对变化、不可分辨的消融格必须写"not resolvable / within seed noise"、失败切片与"模型知不知道"；局限：预注册失败分支、五维弱项）；③ 按清单写各节，引言用 `academic-intro-writing`、各节 `nature-writing`、润色 `nature-polishing` 作可选辅助；④ `draft_plan.py check` 逐项核对（词元重合或精确数字，章节对才算），缺的 FAIL = G6b。清单抓的是"该说的没说、说错了章节"，说错了数字由 G6 numbers/scope 抓。**对比/消融表不要手写**：`make_comparison.py sota|multi|ablation|seeds --csv results/x.csv --out paper/tab_x.tex --md --numbers`（sota=单数据集 SOTA 表，按 --group-col 分 CNN/Transformer 组、--extra Params,FLOPs、最优红/次优蓝、--ours 加粗置底；multi=多数据集并排；ablation=✓/× 组件表、全 ✓ 行加粗；seeds=逐 seed + Mean±Std；--labels 'AP50=AP$_{50}$' 换表头）。`--numbers` 把每格登记进 paper/numbers.csv，G6 直接溯源到 `<out>.source.csv`。G6 = `gate_check.py all`（refs/floats/acronyms/scope/numbers/limits）。**G6e = `claims_check.py`**（2026-10-11）：claims.csv 每行填 `evidence_key`（`rel:rmse_E1:ours:baseA`、`z:rmse_E1:no_dom`、`mean:`、numbers.csv 式单格）与 `expected`（`-19.2±0.2`、`>=2`、`<2`、`+`），关口自己算；正文里每句 "Here we show" / 贡献条目 / "outperforms all" 类强作用域句都必须能对到一行，强作用域行的 scope_words 写清"all = 哪几个基线、哪个数据集、哪张表"。定性主张（§0 对照、协议类）留空 evidence_key，关口 WARN 不 PASS，审稿席位人工看。

**LaTeX 投稿形态（2.7 新增）**：有模板的刊，正文写在 `paper/latex/main.tex`（可 `\input` 分节文件与 figs/*.tex），图只用 `\includegraphics{*.pdf}`。`paper/manuscript.md` 是派生品，不手改：每次改完 .tex 跑 `tex_to_md.py paper/latex/main.tex . --bib paper/refs.bib`（展开 \input，主题注取最后一个 \caption 并附子题注，figures.csv 合并保留 source_data / inspected，项目 bib 不改写），再 `t2p.py check`。G6d = `latex_check.py check`：class 对刊（state.target.latex_class 不符 FAIL）、每张图存在且为 PDF、含 ≥2 张图的 figure 必用 subfigure/subfloat 且包已加载、题注 (a)(b) 对单图 FAIL、\ref 不悬空、bib 文件在、manuscript.md 不比 .tex 旧。表格仍由 `make_comparison.py` 出 .tex 直接 `\input`。
