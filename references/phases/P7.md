# P7 审稿 — 细则

> SKILL.md 一行表的全文版；进入 P7 前读完本文件再动手。关口判据与历史漏法见 [../gates.md](../gates.md)（G7），失败模式总表见 [../lessons.md](../lessons.md)，席位问题、提示模板、红线见 [../review-seats.md](../review-seats.md)，口径见 [../review-rubrics.md](../review-rubrics.md)，各刊审稿表在 `../review-forms/`。

**P7 是本 skill 唯一允许开子代理的阶段（用户 2026-10-28 批准）：审稿与复审的席位各用一个新上下文的子代理，只给 PDF 和审稿表。** 原因：自审时同一个会话带着 prereg、claims 和全部上下文写五个席位，cvpr2027_med2 六条 major 里四条靠收窄措辞关闭，cvpr2027_medical 的输入朝向错误扛过 10 轮自审。独立的是上下文，不是判断力（子代理仍是同一模型家族）；汇报时如实说，最终审稿人是用户。

流程（每步的细则在 review-seats.md）：

1. **冻结稿件**：G6 全绿、编译 PDF，`python scripts/review_packet.py make`（稿件 = `paper/latex/main.pdf`，没有就退到 `paper/manuscript.md` + figures/；`--round N`）。它写 `paper/review_packet/round<N>/`：稿件副本、该刊审稿表 `form.md`、`manifest.json`（sha256 / sha8 / venue / family）、`prompts/<席位>.md`。审稿期间稿子不改。
2. **独立审**：每个 `prompts/*.md` 启动一个全新上下文的子代理（Agent 工具，general-purpose），提示原文整段交给它，**不加 prereg、claims、gap_map、对话、作者笔记**。席位：**R0 区域主席 / 价值**（该刊会收吗？发现是否已知？有没有对最强方法的主表？一句话能说出主张吗？打 rating）、**R1+R3**（方法学与泄漏，一个子代理；写完盲读后才可打开 results/ 与 runs/）、**R2**（新颖性，可检索文献，点名最接近的三篇）、**DA**。
3. **登记**：返回的审稿原文原样贴进 `paper/review_log.md`，标题行 `## Reviewer <席位> (independent, packet <sha8>)` 不改；不删条、不改严重度与类别。每条意见带 `category:`（evidence / validity / novelty / value / clarity / format）。
4. **主会话里的席位**：R4 写作与形状、R5 编辑综合（表 + 建议档位 + 三件事）在本会话做。R0 评分在拒稿线上（cs_conf ≤ 3）时，第一件事是回证据或选题，不是改写。
5. **核实与处置**：「缺失」类意见先全文搜索再处置；每条意见回结果文件复核；处置词表（已改 / 复核通过 / rebut / partial / 需新实验）。**major 写 `处置: 已改 (…)`，不用行内箭头 `→ 已改`**（箭头让该条绕过复审）。改数字回结果文件与 numbers 登记。
6. **复审**：改稿 → 重新编译 → G6 重跑 → `python scripts/review_packet.py rereview --round N --items R0-1,R2-3`（每条 major 一份提示：原意见 + 作者处置 + 改后 PDF）→ **同一席位**用新子代理在改后版本上判 `R0-1 closed: …` 或 `R0-1 OPEN: …`，贴进 `## Re-review <席位> (independent, packet <sha8>)`；`state.review.round` 加 1。
7. **G7 = `review_check.py` 全绿**。

红线：evidence / validity / novelty / value 类 major 只能由独立复审关闭，作者自己写 closed、行内箭头、收窄措辞都不算；收窄主张只有在独立复审接受之后才算修好；validity 类 major 的处置要引用一个在故意弄坏的版本上会失败的检查输出文件（G3b 的 `results/instruments/*_broken.json` 或变异测试）。确实无法开子代理时在 `state.review.independent_waiver` 写原因（G7 降为 WARN，并在汇报里说明审稿是自审）。
