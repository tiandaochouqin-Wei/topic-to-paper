# P7 审稿 — 细则

> SKILL.md 四行表的全文版，从 v2.5 的 SKILL.md 原文逐字下沉；进入 P7 前读完本文件再动手。关口判据与历史漏法见 [../gates.md](../gates.md)，失败模式总表见 [../lessons.md](../lessons.md)。

**P7 审稿**：照 [../review-seats.md](../review-seats.md) 的内置流程做（盲读 → 五席 + 魔鬼代言人 → 编辑综合 → 处置 → 复审；口径 [../review-rubrics.md](../review-rubrics.md)），不依赖外部 skill；每条意见满足「定位 / 被攻击的主张 / 后果 / 怎样才算解决 / 严重度」五点，「缺失」类意见先全文搜索再写，每条意见先回结果文件复核再写入 review_log.md，每条标 [major]/[minor] 并给处置（复核通过 / 已改 / rebut / partial，或在 Phase 2 编辑综合表按 R1-3 编号列出）；修完**必须有 `## Re-review` 小节**逐条关闭 major，state.review.round 加 1，G6 重跑。**major 的处置写 `处置: 已改 (…)`，不用行内箭头 `→ 已改`**（箭头会让该条绕过复审，脚本 WARN）；复审里没关的写 `OPEN: …`。G7 = `review_check.py` 全绿（每条有处置、major 全关闭、round ≥1、gate_report 新于正文、处置里提到的位置在正文里存在）。
