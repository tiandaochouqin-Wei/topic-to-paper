# 失败模式清单

来自五次投稿与三个方向调研。按"症状 → 根因 → 处理"写，关口即由此导出。不含项目具体数字。

## 实验

| 症状 | 根因 | 处理 |
|---|---|---|
| 换一个实现，数字就动 | 归一化分母在不同数据集含义不同 | prereg 写死分母；跨数据集比较前断言分母定义一致 |
| 全量数据得出与窗口数据相反的结论 | 纳入窗口没写死，事后随意切换 | prereg 写死窗口；所有表的表头标口径 |
| 目标域指标好得不合理 | 目标域标签进了训练；或小组退化溢出到邻组 | grep 开关为 0；最小组样本量阈值，不足则丢弃 |
| 基线与提出方法差距稳定但解释不了 | args 里的超参没走到生效分支 | 看日志有无对应列，不看 args |
| 集群结果与本机结果不一致 | 某输入目录缺失被静默关掉 | 删目录 smoke 必须报错 |
| 同 seed 不同机器权重不同 | 算子非确定性 | 主表单一硬件，另立复现表 |
| ckpt 存在但指标是半程值 | 训练中途被驱动热复位杀死，无 traceback | 判训完看 log 条数；温度监控 |
| 两个 Claude 会话互相抢 GPU | 共用 runs/ 与显卡 | 启动前 nvidia-smi 查占用 |
| 参数量与 ckpt 不符 | bench 脚本按默认架构建模 | 加载真实 ckpt 统计 |
| 效应为零 | 分层变量四分位太窄，没区分度 | 先查分层变量量程 |
| 三元组损失无梯度 | 硬负例距离远小于 margin，损失钉在 margin | 检查损失是否随训练变化；增益不可归因于该项 |
| Pearson 残差正交但 Spearman 仍强相关 | 零膨胀下线性残差化失效 | 控制协变量用偏 Spearman；残差自检用读数本身的相关系数 |
| 去均值反而降低相关 | 成对展开后样本非独立 | 成对展开必须置换检验 |
| kNN 读数显示嵌入无信息 | 固定读数低估了嵌入 | 学一个共享映射作为上界再下结论 |
| 零样本在未见基因上静默失效 | 用 nn.Embedding(n_genes, d) 查表 | 任何参数第一维等于实体数就错；必须是共享函数 |
| 两折 transductive gap 符号相反 | 与域漂移同序 | 写下第三折的事前预测再跑 |

## 写作

| 症状 | 根因 | 处理 |
|---|---|---|
| 参考文献字符串对，内容是另一篇 | 人工校对看字符串 | DOI 解析回标题比对 |
| 三篇不同论文合并成一条 | key 用首词+年份 | key 取三词，断言一 key 一标识符 |
| 图/表没人引用 | 只数题注 | 引用集与存在集双向求差 |
| 主指标缩略语从未展开 | 关口只查标题/摘要 | 正文单独关口，判据展开 offset ≤ 首现 offset |
| 公式编号一个渲染路线有一个没有 | 编号是 SVG 字形，抽文本查不到 | 直接查渲染配置 |
| 图在屏幕上清楚印出来糊 | figure.dpi 是屏幕值 | 按印刷宽度算 dpi |
| 字号达标但图例穿线 | 没裁局部目测 | 每张图裁图目测一次 |
| 审稿人第一击是"你说最好，哪个表" | 主张作用域悬置 | 投稿前筛 best/first/all 并回表 |
| cover letter 数字停在上一版 | 投稿文件是独立文件 | 单独关口，正反向对照 |
| 表里的数字无处溯源 | 生成脚本现场算完直接写进正文/表，不落盘（InfoFusion §9.4 的 28 个 CI、EAAI Tables 6/7 的 86 个数） | 凡进表的数，脚本必须同时写 csv/json；numbers.csv 指向它 |
| 盲稿关口把被引作者当泄露 | 参考文献表里有同姓作者 | 盲稿检查先截掉参考文献表 |
| "under any channel loss" 只测了四种 | 全称量化词不在作用域词表 | SCOPE_STRONG 含 any/all/every + 名词 |
| 参考文献超限 | 没提前算预算 | G0 抄硬规则，加一删一 |
| LaTeX 出空白页 | author 间空行 | 模板固定 |
| 公式符号包冲突 | amssymb × newtxmath | 模板固定 |

## 工具

| 症状 | 根因 | 处理 |
|---|---|---|
| 写入文件含 NUL | heredoc 吞反斜杠转义 | 含 `\x00`/`\1` 的文件用 Write 工具 |
| 长文件写入报 unexpected EOF | heredoc >8 KB 截断 | 长文件用 Write 工具 |
| PubMed 取到的 DOI 是别人的 | `.//ArticleIdList` 匹配到参考文献 | 限定 PubmedData |
| 分页模拟与真实 PDF 不符 | 只重排不绑定页首 | 页首加 break-before，判据保守 1 px |
| 会话卡死数小时 | 超大上下文经中转超时重试 | 单会话、不开子代理、及时 /clear |

## 选题

| 症状 | 根因 | 处理 |
|---|---|---|
| 方向做到一半发现饱和 | 没查近 18 个月同主张论文数 | G1 饱和检查 |
| 核心前提被自己的实验否定 | 前提没当假设验证 | prereg 把前提写成可证伪假设，先跑它 |
| 数据申请卡住整条线 | 数据可得性没在 P0 核实 | P0 查数据可得、大小、许可 |
