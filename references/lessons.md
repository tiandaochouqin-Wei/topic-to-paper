# 失败模式清单

来自五次投稿与三个方向调研。按"症状 → 根因 → 处理"写，关口即由此导出。不含项目具体数字。

## 实验

| 症状 | 根因 | 处理 |
|---|---|---|
| 换一个实现，数字就动 | 归一化分母在不同数据集含义不同 | prereg 写死分母；跨数据集比较前断言分母定义一致 |
| 全量数据得出与窗口数据相反的结论 | 纳入窗口没写死，事后随意切换 | prereg 写死窗口；所有表的表头标口径 |
| 目标域指标好得不合理 | 目标域标签进了训练；或小组退化溢出到邻组 | grep 开关为 0；最小组样本量阈值，不足则丢弃 |
| 基线与提出方法差距稳定但解释不了 | args 里的超参没走到生效分支 | 看日志有无对应列，不看 args |
| 集群结果与本机结果不一致 | 某输入目录缺失被静默关掉 | 删目录 smoke 必须报错 |
| 同 seed 不同机器权重不同 | 算子非确定性 | 主表单一硬件，另立复现表 |
| ckpt 存在但指标是半程值 | 训练中途被驱动热复位杀死，无 traceback | 判训完看 log 条数；温度监控 |
| 两个 Claude 会话互相抢 GPU | 共用 runs/ 与显卡 | 启动前 nvidia-smi 查占用 |
| 参数量与 ckpt 不符 | bench 脚本按默认架构建模 | 加载真实 ckpt 统计 |
| 效应为零 | 分层变量四分位太窄，没区分度 | 先查分层变量量程 |
| 三元组损失无梯度 | 硬负例距离远小于 margin，损失钉在 margin | 检查损失是否随训练变化；增益不可归因于该项 |
| Pearson 残差正交但 Spearman 仍强相关 | 零膨胀下线性残差化失效 | 控制协变量用偏 Spearman；残差自检用读数本身的相关系数 |
| 去均值反而降低相关 | 成对展开后样本非独立 | 成对展开必须置换检验 |
| kNN 读数显示嵌入无信息 | 固定读数低估了嵌入 | 学一个共享映射作为上界再下结论 |
| 零样本在未见基因上静默失效 | 用 nn.Embedding(n_genes, d) 查表 | 任何参数第一维等于实体数就错；必须是共享函数 |
| 两折 transductive gap 符号相反 | 与域漂移同序 | 写下第三折的事前预测再跑 |
| 四个预训练 3D 编码器喂的是 SPL 数组，官方布局是 RAS；7 天、10 轮审稿、全部关口都没发现 | 没有任何关口检查「输入约定与官方一致」；发现靠 SuPreM 自带分割头的胰腺 Dice 0.00 vs RAS 下 0.76 | G3b：每个预训练组件登记官方 contract（source = 官方仓库那一行）+ 经同一输入路径的已知答案 + 首批输入图标轴向目测 |
| 「方向测试」得分 0.562（错）vs 0.581（对），据此认定方向没问题 | 校验的破坏版与正确版得分接近，测试不可能失败 | G3b：`broken` 对照必须落到容许带外，落在带内 = 校验无效 |
| 自写训练循环比参考实现低 2.8 AP（29.5 vs 32.3） | persistent dataloader worker 没拿到 `ds.epoch`，增强每 epoch 相同；人工对账才发现 | G3b train_loop 用参考实现对账；G3 `stochastic_keys`：增强种子/哈希逐 epoch 必须变 |
| 146 个 FAIL 变成 PASS | 把 `main_table_runs` 收窄到不含问题 run 的集合，头条数字来自集合之外 | G3 收窄审计集 WARN；要收窄须在 convention_changes 登记 |
| 所有真实项目的 `reproductions: []`；finding 里写「impl: 排除」就结案 | 复现基线与分诊结论没有机械证据要求 | G4：reproductions 为空 WARN；结案 finding 必须带存在的 evidence: 文件，cause: real 另需 control: |

## 写作

| 症状 | 根因 | 处理 |
|---|---|---|
| 参考文献字符串对，内容是另一篇 | 人工校对看字符串 | DOI 解析回标题比对 |
| 三篇不同论文合并成一条 | key 用首词+年份 | key 取三词，断言一 key 一标识符 |
| 图/表没人引用 | 只数题注 | 引用集与存在集双向求差 |
| 主指标缩略语从未展开 | 关口只查标题/摘要 | 正文单独关口，判据展开 offset ≤ 首现 offset |
| 公式编号一个渲染路线有一个没有 | 编号是 SVG 字形，抽文本查不到 | 直接查渲染配置 |
| 图在屏幕上清楚印出来糊 | figure.dpi 是屏幕值 | 按印刷宽度算 dpi |
| 字号达标但图例穿线 | 没裁局部目测 | 每张图裁图目测一次 |
| 审稿人第一击是"你说最好，哪个表" | 主张作用域悬置 | G6e：强作用域句 ↔ claims 行（scope_words 写明 all = 谁、哪个表）↔ 结果文件，四段连通才过 |
| "Here we show" / 贡献条目写得漂亮但没有一个数支撑 | 形状关口只查有没有这句 | G6e：每句 headline 必须对到 claims 行，行里 evidence_key + expected 由关口自己算 |
| cover letter 数字停在上一版 | 投稿文件是独立文件 | 单独关口，正反向对照 |
| 表里的数字无处溯源 | 生成脚本现场算完直接写进正文/表，不落盘（InfoFusion §9.4 的 28 个 CI、EAAI Tables 6/7 的 86 个数） | 凡进表的数，脚本必须同时写 csv/json；numbers.csv 指向它 |
| 盲稿关口把被引作者当泄露 | 参考文献表里有同姓作者 | 盲稿检查先截掉参考文献表 |
| "under any channel loss" 只测了四种 | 全称量化词不在作用域词表 | SCOPE_STRONG 含 any/all/every + 名词 |
| 参考文献超限 | 没提前算预算 | G0 抄硬规则，加一删一 |
| 伪代码写的是想象中的方法，不是跑出结果的那个函数 | 凭记忆写；超参与循环结构在代码里早改过 | G6d：伪代码锚到 state.algorithms 的函数（ast），Require 里的数值对账 ref run 的 args，循环数对照函数 |
| 引言是 1000+ 词的人名目录，贡献条目一条 4–14 个数字，标题 / 摘要 / 结论各说各的，读不出论文要回答什么问题（三个真实 CVPR 草稿，2026-10-23） | 写作清单驱动：draft_plan 把 gap_map 每行变成"点名某篇并说失效点"、把每条主张的数字强塞进贡献条目；没有任何一步要求一句主张和读者的问题 | 论点先行（G6g）：写稿前填 `paper/argument.md`（一句主张、读者的问题、一个 headline 数字、最强反对意见、引言提纲）；`argument_check.py` 查它们在标题 / 摘要 / 引言末段 / 结论里一致；Related Work 按主题成段，引言至多点名 3 篇，只有 headline 的数字进贡献条目 |
| LaTeX 出空白页 | author 间空行 | 模板固定 |
| CVPR 稿的局限段被一次改稿挤出 18 行到第 9 页，项目自写的页数检查照样 PASS，第二次同席位复审才发现（tpami_medimg，2026-11-08）；会议不给作者自查工具，超页直接拒稿 | 检查把「References / LLM Usage Statement」当成一个独立文本块去找，PyMuPDF 把标题和上面的正文并成一块，于是找不到标题、不判；skill 本身只有投稿清单里一条「字数/页数 ≤ 上限」，state.target.page_limit 没有任何脚本读 | G6d（2.12.1）：读 main.tex 旁编译好的 main.pdf，按行找第一个不计页标题（`page_limit_end`，默认 References / Bibliography / LLM Usage Statement / 参考文献），标题落在 page_limit+1 页时按阅读顺序数它前面的正文行，越界 FAIL 并给出第一行；合成 PDF 测试里标题同样被并进正文块 |
| CVPR 2027 把藏起来给审稿工具看的指令（prompt injection）、署名泄露、错模板都列为直接拒稿；skill 的关口只读 .tex / manuscript.md，PDF 里实际印了什么（白字、隐形字、作者栏、元数据、附件、Type 3 字体）没人看 | 「编译出来的东西」从来不是关口的输入；项目各自写一份 pdf_check，换个项目就没了 | `pdf_check.py`（G6d 里由 latex_check 调用，也可对任意 PDF 单独跑）：隐藏文字 / 附件 / JavaScript / Type 3 → FAIL，盲审下元数据或摘要以上出现 blind_terms → FAIL，纸张尺寸对 page_size 或 \documentclass 选项；白字压在照片或有色矢量填充上算看得见（项目脚本只认照片，热力图白字会误报） |
| 公式符号包冲突 | amssymb × newtxmath | 模板固定 |
| 自审 major 靠收窄措辞关闭（六条里四条）、输入朝向错误扛过 10 轮自审、一个项目根本没审；没人问过「这个发现是不是已经有人知道」 | 审稿席位由写稿的同一会话带着 prereg / claims 写；作者自己判「已改」就关闭；没有价值席位 | P7：`review_packet.py` 冻结稿件，R0 / R1+R3 / R2 / DA 各一个新上下文子代理，只给 PDF 与审稿表；evidence / validity / novelty / value 类 major 只能由同一席位在改后 PDF 上独立复审关闭；validity 要引用破坏版会失败的检查输出（G7） |
| G7 报「22 条 major 全部关闭」，其中 R0-2 / R0-6 / R2-7 当时仍是 OPEN；项目日志只好把汇总写成 `R0-2 OPEN, R0-5 OPEN, …` 绕开（tpami_medimg，2026-11-08） | 关闭判定的窗口 `<编号>.{0,160}?closed` 带 re.S，会跨行、跨标题：汇总行 `OPEN: R0-2, …, R2-7. New majors: …`，空一行，再是 `## Re-review R0 (…)` 和 `R0-1 closed: …`，结果 R0-1 的 closed 被记到了 R0-2 头上；`main()` 与 `independent_checks()` 各抄了一份这个正则 | 2.12.1：两处合成一个 `closing()`；`<编号> … closed` 只认同一行，窗口止于下一个条目编号；closed 后面紧跟编号时（`Closed: R0-5, DA-3`）算列表标签，不算前一个编号的关闭；否定词与 OPEN 规则不变。代价：`R1-1 and R2-1 closed` 只关 R2-1，所以一行只写一条判决。同轮补：英文关闭词前面不能紧挨字母或连字符，`unresolved` / `unacceptable` / `disclosed` / `non-closed` 原来也被算作关闭 |

## 工具

| 症状 | 根因 | 处理 |
|---|---|---|
| 写入文件含 NUL | heredoc 吞反斜杠转义 | 含 `\x00`/`\1` 的文件用 Write 工具 |
| 长文件写入报 unexpected EOF | heredoc >8 KB 截断 | 长文件用 Write 工具 |
| PubMed 取到的 DOI 是别人的 | `.//ArticleIdList` 匹配到参考文献 | 限定 PubmedData |
| 分页模拟与真实 PDF 不符 | 只重排不绑定页首 | 页首加 break-before，判据保守 1 px |
| 会话卡死数小时 | 超大上下文经中转超时重试 | 单会话、及时 /clear；子代理只用于 P7/S6 独立审稿 |
| `python -I review_check.py --project …` 崩：ModuleNotFoundError: shape_check；`latex_check.py` ↔ `make_algorithm.py` 互相导入，也一样崩 | `-I` 不把脚本目录放进 sys.path；兄弟模块在函数里懒导入，`--help` 走不到这一步，test_health 发现不了 | 脚本开头把自身目录插进 sys.path（同 review_packet.py）；test_health 用 ast 查每个脚本：导入兄弟脚本之前必须已有 sys.path.insert；三个脚本各用 `-I` 完整跑一遍（2.12.1） |

## 图表（验证轮 15）

| 症状 | 根因 | 处理 |
|---|---|---|
| 关口全绿，用户一眼看出图表不像好刊 | G5 只查 dpi 与"已目测"，目测看的是放大 PNG；图画大后缩进半栏，字号 3.5 pt | 按印刷宽度画；G5 读文本层算印刷字号；目测看渲染后的页面 |
| 没有总览图、定性图 | 选图单只在细则里，没进关口 | G5 按家族查图类型覆盖，缺的要写理由 |
| 关口全绿，稿子只有 1 图 6 表 | 类型覆盖只查"有没有"，数量没人查；写手先交薄版 | G5 按目标刊下四分位查图/表数；第一版就配足 |
| 12 张图里 skill 只画了 3 张，曲线图全靠手写 matplotlib | make_figure 只有 main / ablation / seeds，cs 论文 33–55% 有曲线图 | `curves` 子命令读长表画多系列曲线带种子带 |
| 逐种子表把 NLL 最大的那行加粗 | make_comparison seeds 一律取最大均值 | `--lower` 贯通 make_figure 与 make_comparison seeds；未写 `--lower` 时按 state 的 metric_direction / primary_direction，再按列名正则（metric_direction.py） |
| 10 seed 均值的消融效应被判「不可分辨」，配对检验却 p=0.003 | 噪声带固定用单 run 口径 σ√2 | 识别 n_seeds / 逐 seed 行，均值用 σ√(1/n+1/n_ref) |
| 错的 arXiv 号（量子光学论文）顶替 NeurIPS 2018 论文过了 G1 | refs 关口只核 DOI 标题，不核 arXiv；无 DOI 的会议论文没有合法出路，逼人填号 | arXiv 号按 abs 页标题核验；官方论文集 URL 可作标识符，须可访问、HTML 时核标题 |
| P5 把其它图路由到本机没有的 skill | 路由表写了未安装的 skill 名 | 路由只指向存在的 skill；make_figure 先试 |
| 本 skill 出的每张 PDF 都嵌 Type 3 字体 | matplotlib 默认 pdf.fonttype=3，没人改；G5 不查字体表 | rcParams fonttype 42；G5 用 pypdf 查 Type 3 → FAIL |
| 图存出来才发现缺字方框 / 刻度挤成一团 | 存图后才看 PNG | 存图前内存渲染一次审版面（scipilot 的做法），缺字直接退出 |
| 非标准数据图没有默认去处，每次现想 | 路由只列了泛用画图 skill，没有"先剖析数据再选图型"的那一个 | 装 `scipilot-figure-skill`，路由默认指它；R / Nature QA 走 nature-figure |
| 双纵轴图四条线挤在一起 | 想省一张图 | 一个面板一个轴；G5 对左右都有轴标签的页 WARN |
| 主表里方法行与基线行数字相同还标红加粗 | 方法退化为基线却照常排名 | 合并为一行并写明，或展示为一族 |
| 方法总览图是手画的卡通，与跑出结果的模型对不上（cvpr2027_medical Fig 1 b/c；三份真实稿都没有 Fig 3 式总览图） | 总览图没有来源，改了代码图不跟着变，没有关口把图和模型对账 | `make_architecture.py trace` 从跑结果的类前向追出图，G5 里 `check` 重新 trace 对账；手改只许挪、合并，不许加模块 |

## 理论与证明（研究稿含命题时；验证轮 13）

| 症状 | 根因 | 处理 |
|---|---|---|
| 全部关口 PASS，对抗审稿仍发现命题的证明不成立 | 关口查形状与溯源，不判证明；五席审的是文本不是推导 | P7 R1 席对每条命题独立重推证明：量词、期望 vs 概率、比值损失的分母、"几乎处处"的条件逐项核 |
| "不可能"写在推论之外（推论只证了某个界平凡） | 把"这个界平凡"读成"问题不可能" | 不可能性陈述必须有下界命题；scope 关口 WARN 列出不可能性措辞，审稿席回表到命题 |
| 新写的理论陈述在同一轮里又写错一次 | 写完能编译、关口全绿就当作对了 | 新增或改写的命题当场独立重推；定量下界不要写成"K ≤ 某值不可能" |
| 正文里推导出来的阈值写错（临界 n 差 5） | 阈值不在 numbers.csv，也不在结果文件 | 派生阈值写成公式，P7 代入各任务的 n 复算 |
| 置信区间的重采样单位不是 prereg 写的单位 | 划分共用同批图像，按划分重采样省事但偏窄 | prereg 写明重采样单位；P7 R1 席核对分析脚本 |
| 主表里"我们的方法"与基线数字逐格相同 | 方法在小样本下数学上退化为基线 | 展示为一族（多个超参成员）并写明退化条件，不要两行并列标红加粗 |
| 摘要里的"覆盖对从不超 α"换一个预测器就被推翻 | 单对风险是少量测试图的均值，噪声大；保证只对期望成立；只在一个预测器上观察到 0 次 | 经验陈述里的"从不/每一对"只有在换组件（预测器、测试集大小）后仍成立才写进摘要；否则写平均量 |
| 弱预测器 + 小 n_cal：表里平凡集的风险 0.000 被排成最优 | 平凡集（λ = 1）风险为零但集合空洞 | 表格印 triv.，至少一半平凡的格子加剑号且不参与排名，同列可比格不足三个时不标红蓝 |
